# One production shared backend — 2026-11-10

The public compiler now generates the caller-owned shared backend by default. `call` ownership, `always`/`chunked`/`hybrid` policies, ordinary output files and the owned-session application API are retired. The CLI, public Python configuration and generator reject removed settings before publication. `sections` and `auto` use the same graph/coherence implementation; native/GPU/automatic runtime modes remain available for diagnosis. Shared runtime/entry ABIs and artifact schema 2 remain unchanged.

The pipeline's old call-region adapter is retired, including its whole-array output rewrite and ordinary fallback-query contract. Current local integration uses `resident-build` or checked source graphs. `pipeline run` defaults to the native baseline; local GPU runs require explicit source facts. Existing artifacts and timing controls are preserved.

A new 12-pass test exposed a remaining call from shared generation into the old four-unit slab planner. Production graph generation and owner dispatch now bypass that prototype entirely. The public `pipelined` slab switch is retired; graph batching uses the common task queue. Direct, pinned, automatic and diagnostic coalesced transfers retain their existing coherence implementation. Historical ordinary/slab implementations remain private reference fixtures, not application fallbacks. Twenty-five numerical test modules now name their historical factory explicitly. Final removal of remaining private helpers and frontend configuration coupling is still pending.
